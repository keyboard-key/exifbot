# exifbot
Бот который анализирует изображения и видео и может очищать метаданные для них через EXIFtool, а также простенькая генерация изображений с помощью Pollinations.ai

Требует:
- Установвленный EXIFtool, а в main.py указан путь к нему
- Папку temp (там же где и main.py)
- Файл .env, в котором указан токен в "TELEGRAM_TOKEN=" (без кавычек) (там же где и main.py)
