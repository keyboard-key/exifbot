# exifbot
Telegram бот который анализирует изображения и видео и может очищать метаданные для них через ExifTool, а также простенькая генерация изображений с помощью Pollinations.ai

Требует:
- Установленный ExifTool (exiftool.exe файл, не exiftool(-k).exe), а в main.py указан путь к нему
- Папку temp (там же где и main.py)
- Указание токена Telegram бота в .env

Установить ExifTool:
https://exiftool.org/
